1. Lettura dei valori di configurazione

   Leggere l'input dato al programma. Il subject specifica che il
   programma è chiamato nel seguente modo

   python3 a_maze_ing.py config.txt

   L'obiettivo è prendere il primo argomento, aprire il file, leggere
   il contenuto del file, e tirare fuori i valori per i seguenti
   parametri

   - WIDTH : int
   - HEIGHT : int 
   - ENTRY : (int, int)
   - EXIT : (int, int)
   - OUTPUT_FILE : str
   - PERFECT : bool

   Per fare questo possiamo fare una classe MazeConfig nel seguente modo:

   - Passare al costruttore il path del file da cui leggere i valori
     della config

   - Durante la costruzione aprire il file e leggere i valori

   - Esporre i valori letti tramite dei metodi

     WIDTH -> getWidth()
     HEIGHT -> getHeight()
     ENTRY -> getEntry()

   Usage:

    mazeConfig = MazeConfig("./config.txt")
    
    print(mazeConfig.getWidth())
    print(mazeConfig.getHeight())
    startingPoint = mazeConfig.getStart()

 2. Classe per lavorare con labirinto

    Definire la classe principale Maze che verrà utilizzata per
    generare il labirinto. Questa classe deve permettere all'utente di
    effettuare le seguenti cose:

    0. Costruire un maze di dimensioni date

       maze = Maze(width, height)

    1. Ottenere dimensioni (WIDTH x HEIGHT)

       width, height = maze.getDim()
    
    2. Dato un punto e data una direzione, dire se esiste un muro

       wall = maze.getWall(x, y, direction)
    
    3. Dato un punto, dire se quel punto è chiuso in quattro mura

       isClosed = maze.noAcess(x, y)

    4. Dato un punto, costruire un muro in una direzione in modo da
       mantenere la coerenza del labirinto nei punti adiacienti

       maze.buildWall(x, y, direction)

    5. Dato un punto, distruggere un muro in una direzione in modo da
       mantenere la coerenza del labirinto nei punti adiacenti

       maze.destroyWall(x, y, direction)

    6. Ritorna una lista di punti neighbors accessibili

       maze.neighboursPoints(x, y)
