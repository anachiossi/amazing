bisogno della classe che gen.generate() ritorna.

-------------------------------------------------------------

3. Coordinate: (row, col)

Internamente tutto e' (row, col). grid[row][col]. Basta.

La config del subject scrive ENTRY=x,y (colonna,riga).
La conversione avviene UNA volta nel parser, UNA nel writer.

Bit muri (1 = chiuso):

  bit 0 = N = (row - 1, col)
  bit 1 = E = (row, col + 1)
  bit 2 = S = (row + 1, col)
  bit 3 = W = (row, col - 1)

-------------------------------------------------------------

4. Flusso dati

config.txt → MazeConfig → MazeGenerator → Maze → writer
                                             ├──→ terminal
                                             └──→ graphic

Nessuno chiama all'indietro.
